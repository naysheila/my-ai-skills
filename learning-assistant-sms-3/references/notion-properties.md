# Notion Property Schema Reference

Agar Notion MCP Server dapat membaca status belajarmu dengan presisi, pastikan Database / Page Mata Kuliah di Notion memiliki properti standar berikut:

- **Topik Utama** (Title / Text): Nama materi (misal: `Inheritance & Polymorphism`)
- **Status Pemahaman** (Select): `Perlu Dites` | `Paham Konsep` | `Stuck / Error` | `Mastered`
- **Tipe Catatan** (Select): `Sub-Poin Khusus` | `Judul Besar` | `Ringkasan Modul`
- **Tanggal Belajar** (Date): Tanggal terakhir materi diulas
